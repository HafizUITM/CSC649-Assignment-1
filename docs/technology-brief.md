# Part C: Specialized Technology Brief

## C1. Fundamental Concepts
User Experience (UX) Architecture in Fintech combines visual hierarchy, cognitive load theory, and interaction design to optimize decision-making workflows. By organizing information into clear visual zones, reducing task depth (clicks-to-complete), and providing immediate micro-interaction feedback (e.g., rate change animations), cognitive strain is minimized, driving higher user conversion and platform trust.

## C2. Frameworks, Models, Methods, and Tools
1. **Goal-Directed Design (GDD) Framework:** A methodology focused on user personas, context scenarios, and mapping goals directly to UI components to prevent feature bloat.
2. **System Usability Scale (SUS):** A standard 10-item industry questionnaire model used to quantitatively measure interface usability and user satisfaction.
3. **Figma & Design Systems:** Industry-standard vector prototyping tools used to enforce visual consistency (atomic design components, design tokens, responsive auto-layout frames).

## C3. Fit to Problem, Benefits, Risks, and Alternative
* **Fit & Benefits:** Applying UX Architecture directly addresses Public Gold's high conversion friction. Unifying GAP, EPP, and Shop into a single navigation framework reduces task completion times and eliminates confusion.
* **Limitations & Risks:**
  1. *Change Resistance:* Legacy users accustomed to old workflows may initially experience unfamiliarity with restructured navigation.
  2. *Development Overhead:* Transitioning legacy database backend flows to support automated, real-time UX components requires structural software refactoring.
* **Alternative Approach Comparison:** An alternative approach would be **Process Automation via Backend Chatbots (RAG/AI Agents)**. While a chatbot could answer questions about EPP schedules, it does not solve the fundamental visual clutter or manual payment slip upload friction. Therefore, **UX Architecture & DSS** is chosen as the primary technology because it addresses structural usability at the root level.
